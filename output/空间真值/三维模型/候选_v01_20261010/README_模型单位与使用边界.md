## 单位与坐标

- 源场景：毫米，平面为项目局部 `X/Y`，竖向为 `Z`。
- GLB：米，Y-up。
- OBJ：毫米，Y-up；文件名中的 `_mm` 用于提示导入单位。
- 轴映射：`world X = local X`、`world Y = local Z`、`world Z = local Y`。
- 公共室内、茶室和露台完成地面均位于源 `Z=0`。
- 模型保留的项目局部坐标只用于空间校核，不是测量控制网或施工放样坐标。

## 导入设置

### GLB

1. 导入单位使用米。
2. 保持 Y 轴向上。
3. 不再二次缩放；若软件把 GLB 当毫米读取，应改导入单位，不要修改模型本体。
4. 节点 `extras` 保留对象 ID、中文名称、图层、状态、来源、源边界和尺寸。

### OBJ + MTL

1. 把 OBJ 与 MTL 放在同一目录。
2. 导入单位明确设置为毫米。
3. 保持 Y 轴向上。
4. 若目标软件只支持米制 OBJ，导入时统一使用 `0.001` 比例；不要另存后把该比例误认为现场尺寸修订。

## 本地查看器

在项目根目录运行：

```powershell
python -m http.server 49344 --directory "output/空间真值/三维模型/候选_v01_20261010"
```

浏览器打开：

`http://127.0.0.1:49344/viewer/`

查看器全部依赖已放在 `viewer/` 内，不需要外部 CDN。支持图层开关、对象点选、全景、重置及俯视/轴测/V01-R1/V02-R1 四个预设机位。

## 模型内容

- 零厚度地坪：西侧室外露台、公共大厅、面山露台带、东端过渡区、茶室。
- 推导占位体块：卫生间、楼梯、电梯/井道；这些不是施工级墙体模型。
- 已确认结构：C1-C4 四根 `105×150mm` 钢柱。
- 已确认固定设计：茶室墙体与唯一窗、吧台、800mm 上下翻门、E1-E5 设备段及完整设备背景墙。
- 控制面：茶室 `2450mm` 天花、其余室内 `2700mm` 天花，默认关闭。
- 空图层：钢屋架与未来玻璃系统；因可靠几何不足，仅保留图层和“需现场复尺”状态。

## 明确排除

- 钢屋架、压型钢板、消防管和未复尺梁体。
- 给排水、地漏、插座、开关、灯具、风管和设备管线。
- 活动家具、人物、植物、软装和正式饰面。
- 未来玻璃门的分格、轨道、开启与收纳方式。
- 未确认墙厚、楼板厚度、结构节点和施工收口。
