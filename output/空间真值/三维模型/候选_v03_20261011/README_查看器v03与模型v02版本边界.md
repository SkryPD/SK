# 楼顶封顶核验查看器 v03

## 当前状态

- 状态：`candidate_viewer_v03`。
- 模型版本：`rooftop-universal-3d-model-v02`。
- 查看器版本：`v03`。
- 用途：核验茶室 `2450mm`、其余室内及开放通道 `2700mm` 的两级天花关系，并保留去顶查看能力。
- 禁止用途：施工放样、吊顶下单、龙骨吊杆深化、消防及机电深化、门窗与防水节点下单。

## 版本边界

本目录没有创建新的几何版本。GLB、OBJ 和 MTL 均继续使用 v02 文件名，并与已归档的 `候选_v02_20261011` 对应文件 SHA-256 完全一致。v03 只修改离线查看器：

1. 图层开关递归同步父图层及全部子对象。
2. 增加“封顶核验”高位轴测预设。
3. 进入该预设自动显示两级天花；切换到其他预设自动恢复去顶。
4. 天花在查看器内临时显示为 `62%` 透明暖灰色；此样式不写回 GLB。
5. 镜头按天花实际包围盒和当前视口比例自适应，兼容桌面及 `390×844` 手机视口。

## 打开方式

当前本地服务：

`http://127.0.0.1:49346/viewer/`

服务重启时，在本候选目录运行：

```powershell
python -m http.server 49346 --bind 127.0.0.1
```

然后打开同一地址。查看器依赖均在 `viewer/` 内，不使用外部 CDN。

## 操作说明

- `封顶核验`：自动开启两级天花并对两块顶面自适应取景。
- `俯视 / 轴测 / V01-R1 / V02-R1`：恢复去顶状态。
- `两级天花` 复选框：手动显示或隐藏父图层及两个天花子对象。
- 面板按钮：桌面端收起侧栏，手机端展开或收起底部控制面板。
- 全景与重置按钮：保持原 v02 查看器功能。

## 已确认空间关系

- 茶室天花：范围 `[34240,6160,37440,10260]mm`，完成面 `Z=2450mm`。
- 其余室内及开放通道天花：范围 `[18390,0,34240,6160]mm`，完成面 `Z=2700mm`。
- 西侧室外露台与面山露台带：不设天花。
- 唯一窗、窗上 `570mm` 封墙、墙体、柱网、吧台与设备：本轮未改动。

## 使用边界

顶面在模型中是零厚度控制面，只表达范围与完成面标高，不表达吊顶厚度、龙骨、吊杆、灯具、检修口、消防、风管、防水或收口节点。所有施工尺寸仍以正式图纸、现场复尺和专业深化为准，不得从截图或模型画面反推施工尺寸。
