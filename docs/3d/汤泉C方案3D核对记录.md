# 汤泉 C 方案 3D 核对记录

## 成果定位

本组成果是基于现有平面资料建立的几何受控概念表达，包括一张完整区域拆顶轴测图和一张由同一几何母版导出的男汤室内透视图。成果用于确认室内设计方向和空间氛围，不是 BIM 模型、施工图或规范合规文件。

## 依据

- 首要图纸依据：《温泉、娱乐室平面.pdf》及其汤泉区域截取图 `tmp/pdfs/selected/spa_function_crop.jpg`。
- 几何控制依据：`output/3d/spa-c-axonometric-guide.png` 与 `output/3d/spa-c-interior-guide.png`。
- 风格依据：已确认 C 方案，即 30% 静谧自然与 70% 明快现代自然。
- 池体及施工参考：`tmp/pdfs/outdoor/p10.jpg`、`p11.jpg`、`p12.jpg`，仅作概念理解，最终以温泉设备专业深化为准。

## 已核对的几何不变量

- 男汤位于北侧/图面上方，女汤位于南侧/图面下方。
- 男汤、女汤各有且仅有一座长方形池，两池保持同一方向和 `8180 × 4240 mm` 图示比例。
- 池体在各自 `8680 × 6580 mm` 汤区内居中：东西边距各约 `250 mm`，南北边距各约 `1170 mm`。
- 北侧温泉设备房保持约 `10000 × 7260 mm` 的邻接外壳，不深化内部。
- 西侧过渡/洗浴休息空间、独立入口与汤池阈口关系保留。
- 男女汤之间的 `140 mm` 绿化隔离线和东侧约 `1000 mm` 绿化边带保留。
- 拆顶仅为轴测表达方式；室内透视保持完整顶面，空间按全室内封闭处理。

## C 方案表达

- 地面及池边采用浅暖、低反光的防滑石材概念。
- 顶面采用防潮木纹线性吊顶，墙面以暖白矿物涂层和受控浅绿色肌理端景为主。
- 灯光以明亮均匀环境光配合约 `3200K` 建筑照明；球形防潮壁灯用于形成轻松、有秩序的视觉节奏。
- 绿化集中于隔离带、东侧边带和室内端景，不做满铺式商业洗浴装饰。
- 轴测图中的洗手台、坐凳、灯具及室内图中的水帘、盆栽属于概念性 FF&E/端景，不代表施工图已确定构件。

## 设计暂定值

- 室内净高 `3200 mm`。
- 门洞高度与构造、池深、池内台阶和坐凳、扶手、吊顶节点、窗洞及机电风口。
- 排水沟、地面坡度、防水收口、检修口、通风除湿、灯具防护等级和设备接口。

## 生成与尺寸说明

- 写实化使用官方 imagegen CLI、`gpt-image-2`，并按用户要求通过 `config.toml` 相同节点 `https://shacorouter.cc/v1` 调用；未记录或展示 API 密钥。
- CLI 请求尺寸为 `2048 × 1152`，但该节点实际返回轴测图 `1448 × 1086`、室内图 `1672 × 941`。官方 CLI dry-run 已确认请求参数正确，保存过程无二次缩放。因此保留节点原生像素和比例，并在接触表中等比装版，不做拉伸。
- AI 写实化可能对非几何性的 FF&E、灯具细节和端景做概念补充；施工深化不得从效果图反推精确尺寸。

## 专业复核要求

建筑、结构、室内、机电、消防、温泉设备及施工单位须结合最新施工图和现场复尺，对结构边界、净高、门窗、无障碍、池体构造、防水、防滑、排水、除湿、卫生、消防和检修条件进行专业复核。当地规范和审批要求以主管部门及注册专业人员意见为准。
