本组图为由同一毫米制母版导出的几何受控概念表达，不是 BIM、施工图、材料订货单、灯具下单图或规范合规文件。

## 最终选择

- 用户最终选择灯具 B：取消球形壁灯，采用少量小型无边防潮筒灯，并保留隐藏线性灯。
- 灯具 B 以 `spa-bright-natural-interior-b.png` 为准；轴测图用于完整区域几何核对，其中的概念照明符号不作为最终灯具选型或定位依据。

## 已核对

- 男汤在北、女汤在南，各一座约 `8180 × 4240 mm` 汤池。
- 每区一张四人圆桌、四把圆角椅；男汤桌椅/柜体靠北外墙，女汤靠南外墙。
- 全部长凳取消；中央入口—洗手—汤池主通道无阻挡。
- 过渡区与汤池区之间为通高细框/隐框玻璃和防潮实体门；室内透视中的实体门以 `90°` 开启状态表达。
- 全室内封闭；墙地面浅冷灰米白，木色浅灰白橡木。
- 全部建筑照明约 `4000K`；灰绿色约 10%；端景无水帘。
- 灯具 B 室内图未见球形壁灯，保留隐藏线性灯，并以少量小型筒灯提供中性白基础照明。
- 灯具切换未改变机位、汤池、门、玻璃、家具、柜体、植物、端景和主要色材关系。

## 暂定与专业复核

净高 `3200 mm`、柜体进深、门扇构造、池深、台阶、扶手、防滑等级、防水、排水坡度、除湿、新风、消防、无障碍、灯具防护等级和设备接口均须由专业单位结合现场及当地规范深化。

## 生成方式

写实化使用官方 imagegen CLI、`gpt-image-2`，并通过当前 `config.toml` 的同一模型提供商节点调用；本记录不保存或展示 API 密钥。

## AI 图像限制

AI 写实化可能改变非几何性纹理、软装和灯具细节；不得从效果图反推施工尺寸。若图像与控制图冲突，以控制图和原平面为准。筒灯数量、间距、功率、配光、防护等级及检修方式须由照明、电气和室内专业深化后确定。
