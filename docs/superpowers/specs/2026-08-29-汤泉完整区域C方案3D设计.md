# 汤泉完整区域 C 方案 3D 设计基准

## 1. 目标与交付

在《温泉、娱乐室平面.pdf》所示汤泉区域基础上，建立一套几何一致的 3D 概念模型，并输出：

1. 拆顶鸟瞰轴测图：用于核对男汤、女汤、各自过渡/洗浴休息空间、中间绿化隔离带、入口及设备房外壳的空间关系。
2. 室内透视图：用于表达已选定的 C 方案，即 30% 静谧自然与 70% 明快现代自然的室内氛围。

两张图必须基于同一几何母版，不得在视图之间移动门洞、改变池体比例或重组动线。

## 2. 建模范围

- 男汤及其相邻过渡/洗浴休息空间。
- 女汤及其相邻过渡/洗浴休息空间。
- 男女分区之间的绿化隔离带和独立出入口。
- 温泉设备房仅表现建筑体块及与汤泉区的邻接关系，不深化设备房内部。
- 不包含中央大庭院、棋牌、KTV、休闲室等娱乐区域。

## 3. 几何依据

### 图纸可直接读取

- 总平面以《温泉、娱乐室平面.pdf》为首要依据。
- 单个男汤/女汤图示池体内部平面尺寸约为 `8180 × 4240 mm`。
- 两个汤区沿南北方向布置，中间设绿化隔离带；各自通过西侧过渡空间进入。
- 温泉设备房位于汤泉区北侧，平面标注约 `10000 × 7260 mm`。
- 池体深化、防水、贴砖、给排水点位和设备接口以温泉设备供应商后续深化为准。

### 设计暂定值

- 全室内封闭，不采用露天或半室外汤院。
- 室内净高暂定 `3200 mm`，仅用于概念建模；现场及建筑图确认后调整。
- 外围及分隔墙高度随室内净高暂定，墙厚、结构柱、梁位以施工图复核。
- 门洞高度、吊顶构造、窗洞和机电风口因现有资料未完整标注，在不改变平面门洞位置的前提下合理暂定。
- 汤池水深、台阶和坐凳构造仅做示意，不作为施工尺寸。

## 4. C 方案空间语言

- 基调：明亮、年轻、洁净、自然，避免传统商业洗浴中心的强装饰感。
- 地面与池体：浅暖色防滑石材或细颗粒防滑砖，控制反光，强调排水沟与干湿边界。
- 天花：防潮木纹线性吊顶或局部木格栅，形成温暖纵向秩序。
- 墙面：暖白矿物涂层与小面积浅绿色肌理面；绿色集中在视觉节点，不满铺。
- 灯光：约 3200K 的均匀基础照明，配合连续但不过密的乳白球形壁灯或防潮壁灯；避免眩光和水面强反射。
- 绿化：中间隔离带与端景承担主要自然记忆点，室内盆栽数量受控，并选耐湿环境方案。
- 安全：显性考虑防滑、排水、扶手、池边圆角、照明防护等级、检修、通风除湿和隐私。

## 5. 鸟瞰轴测图表达

- 采用约 35-45 度俯视角的拆顶轴测图。
- 清楚展示两个独立汤区、各自入口、过渡空间、中间绿化隔离带、池体边界和设备房外壳。
- 男汤与女汤可用低调文字标签辅助识别，但不增加图纸不存在的房间。
- 屋顶整体移除，墙体保留至便于读取空间的高度；不采用夸张爆炸分解。
- 画面以几何和动线可读性优先，材质真实度次之。

## 6. 室内透视图表达

- 首张室内透视优先表现一个完整汤区，并通过入口/隔离带或镜像逻辑说明另一侧采用同一体系。
- 机位位于过渡空间进入汤池的位置，能同时读到池体、主要通道、洗浴/休息节点和室内端景。
- 全室内封闭条件下，通过顶部漫射光、受控窗洞或室内绿化端景提升自然感；不虚构露天天空。
- 透视图必须保持与鸟瞰图相同的池体方向、门洞位置和主要墙体关系。

## 7. 生成与核对流程

1. 从原平面提取汤泉完整区域并建立清晰几何底图。
2. 先生成无风格干扰的拆顶体块母版，核对男女分区、池体比例、入口和设备房邻接关系。
3. 将 C 方案材质和灯光应用到轴测图。
4. 使用同一母版生成室内透视图，并锁定几何不变量。
5. 对照原平面逐项检查：男/女位置、双池数量、池体长宽比例、隔离绿带、入口方向、设备房位置。

## 8. 限制与专业复核

本次成果为概念设计和空间沟通资料，不是 BIM 模型、施工图或规范合规文件。结构、净高、门窗、池体构造、防水、防滑、排水坡度、机电、除湿、消防、卫生和无障碍要求，须由建筑、室内、结构、机电及温泉设备专业结合最新施工图和现场复尺确认。
