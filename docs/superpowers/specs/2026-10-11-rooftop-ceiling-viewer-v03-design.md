# 楼顶整层封顶核验查看器 v03 设计说明

## 背景与根因

业主已确认茶室完成天花为 `2450mm`，其余室内及开放通道完成天花为 `2700mm`，室外露台不设天花。现有通用三维模型已经包含两个天花对象，但查看器只切换 `design_ceiling` 父图层；天花子对象仍保留隐藏状态，因此勾选“两级天花”时存在看不到封顶面的风险。

## 选定方案 B

在不改变 v05 空间真值和 v02 几何模型的前提下，新建 v03 查看器候选：

1. 修复图层开关，使父图层及其全部子对象同步显示或隐藏。
2. 增加“封顶核验”预设按钮。
3. 进入该预设时自动显示两级天花，并切换到能同时看见主厅与茶室顶面的高位轴测镜头。
4. 离开该预设时恢复去顶显示，避免遮挡吧台、墙体与内部空间。
5. 天花使用较清楚的半透明暖灰色；只表达完成面标高，不表达厚度和构造。

## 硬约束

- 茶室天花：完整覆盖茶室 `3200 x 4100mm`，`Z=2450mm`。
- 其余室内天花：覆盖公共大厅及开放通道，`Z=2700mm`。
- 西侧室外露台和面山露台：不生成天花。
- 唯一窗、窗上 `570mm` 封墙、墙体、柱网、吧台及设备均不改变。
- v03 仅为查看器与可视化修订，继续使用 `rooftop_truth_model_v02.glb`，不得伪装成新的施工几何版本。

## 交互规则

- 手动勾选“两级天花”：父图层和两个天花子对象全部可见。
- 手动取消：父图层和两个天花子对象全部隐藏。
- 点击“封顶核验”：自动勾选“两级天花”，显示高位轴测。
- 点击“俯视 / 轴测 / V01-R1 / V02-R1”：自动关闭天花，恢复原有去顶检查逻辑。
- “模型全景”和“重置当前视角”保持原有功能。

## 版本与交付

- 旧版保留：`output/空间真值/三维模型/候选_v02_20261011/`
- 新版目录：`output/空间真值/三维模型/候选_v03_20261011/`
- 新版包含离线查看器、同一 v02 几何模型、版本说明、核验报告及“整层封顶核验”截图。

## 验收标准

- 自动测试证明图层切换会同步更新所有子对象。
- “封顶核验”按钮、标签和预设逻辑存在于离线查看器。
- 浏览器实测进入预设后两个天花对象均可见，离开后均隐藏。
- 截图中两级天花非空白、可辨识，且露台区域没有顶面。
- 浏览器控制台无错误；桌面和手机视口不发生文字或控件重叠。

## 使用边界

本模型只用于空间关系和设计核验。吊顶厚度、龙骨吊杆、消防、风管、灯具、检修口、防水及门窗收口均须现场复尺和专业深化，不得从模型或截图反推施工尺寸。
