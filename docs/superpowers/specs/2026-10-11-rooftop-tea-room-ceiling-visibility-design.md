# 楼顶茶室封顶可视化设计说明

## 目标

在不改变 `rooftop-whole-floor-truth-model-v05` 空间真值的前提下，补充两张能直接看见茶室封顶关系的三维灰模候选图，解决原 `02_整层去顶轴测灰模_v05.png` 因主动隐藏天花而无法看见封顶的问题。

## 已确认几何

- 茶室平面范围：`3200 x 4100mm`，坐标范围 `X=34240..37440`、`Y=6160..10260`。
- 茶室完成天花：全域 `Z=2450mm`。
- 唯一窗洞：`3220 x 2100mm`，`Z=350..2450mm`。
- 窗上封墙：`Z=2450..3020mm`，高度 `570mm`。
- 本轮只改变显示方式，不移动墙、窗、通道、吧台、设备或柱网。

## 输出方案

### A 完整封顶轴测

- 显示茶室完整的 `2450mm` 封顶控制面。
- 封顶面采用不透明浅灰暖色，与墙体区分，并标注 `茶室完整封顶面 Z=2450`。
- 允许顶部遮挡部分室内，因为本图只用于证明封顶面的完整覆盖范围。

### B 半透明剖切核验

- 同一几何、同一观察方向显示半透明封顶面。
- 通过局部剖切和透明叠加，同时看见唯一窗、窗上 `570mm` 封墙及封顶面闭合关系。
- 标注 `窗顶2450 = 天花2450` 和 `上部封墙570`。

## 文件与状态

- 新输出目录：`output/空间真值/整层灰模/封顶可视化_候选_v01_20261011/`
- 两张输出均为候选图，不覆盖 v05 文件。
- 新脚本只读取 v05 `scene_spec()`，不得复制或重新定义空间真值尺寸。
- 输出附带简短核验报告，逐项记录 `pass / fail / uncertain / not_visible`。

## 使用边界

封顶面是完成天花标高控制，不表达龙骨、吊杆、结构板厚、检修口、消防、风管、防水和门窗收口构造，不得用于施工放样。
